# Kernenergie in Deutschland – Chronologie der zentralen Ereignisse

## Phase 1 – Aufbau und Euphorie (1955–1969)

| Jahr | Ereignis                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------- |
| 1955 | Gründung des Bundesministeriums für Atomfragen ("Atomministerium"); erster Minister: Franz Josef Strauß                    |
| 1957 | Erster Forschungsreaktor Deutschlands geht in Garching kritisch ("Atomei", FRM)                                            |
| 1959 | Verabschiedung des **Atomgesetzes** (Gesetz über die friedliche Verwendung der Kernenergie), in Kraft 1960                 |
| 1961 | Erstes kommerzielles Versuchskernkraftwerk **Kahl (VAK)** speist Strom ins Netz – Beginn der deutschen Atomstromproduktion |
| 1969 | Inbetriebnahme erster großer Leistungsreaktoren (u. a. Obrigheim)                                                          |

## Phase 2 – Ausbau und der Beginn des Widerstands (1970er)

| Jahr | Ereignis                                                                                                                     |
| ---- | ---------------------------------------------------------------------------------------------------------------------------- |
| 1973 | Ölpreiskrise – Kernkraft wird zur energiepolitischen Priorität                                                               |
| 1975 | Besetzung des Bauplatzes **Wyhl** – Geburtsstunde der bundesweiten Anti-Atom-Bewegung                                        |
| 1977 | Festlegung **Gorlebens** als Standort für ein nukleares Entsorgungszentrum; Großdemonstrationen in Brokdorf, Grohnde, Kalkar |
| 1979 | Reaktorunfall in **Harrisburg/Three Mile Island** (USA); 100.000 demonstrieren in Bonn und Gorleben                          |

## Phase 3 – Tschernobyl und die Politisierung (1980er)

| Jahr       | Ereignis                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 1980       | Gründung der Partei **Die Grünen** – Atomausstieg als Kernforderung                                    |
| 26.04.1986 | **Reaktorkatastrophe von Tschernobyl** – radioaktiver Niederschlag auch über Deutschland               |
| Juni 1986  | Gründung des **Bundesumweltministeriums (BMU)** als direkte Reaktion auf Tschernobyl                   |
| 1985–1989  | Betrieb und Stilllegung des Thorium-Hochtemperaturreaktors **THTR-300** (Hamm-Uentrop) nach Störfällen |
| 1989       | Aufgabe der Wiederaufarbeitungsanlage **Wackersdorf** nach jahrelangen Protesten                       |

## Phase 4 – Konsolidierung und erster Ausstiegsbeschluss (1990–2002)

| Jahr       | Ereignis                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| 1990       | Abschaltung der sowjetischen Reaktoren in **Greifswald/Lubmin** nach der Wiedervereinigung                     |
| 1991       | Endgültige Aufgabe des nie betriebenen Schnellen Brüters **Kalkar** (heute Freizeitpark)                       |
| 14.06.2000 | **Atomkonsens** – Vereinbarung zwischen Schröder-Regierung und Energieversorgern über den geordneten Ausstieg  |
| 27.04.2002 | Novelle des Atomgesetzes: gesetzliche Verankerung des **ersten Atomausstiegs**, Begrenzung der Reststrommengen |

## Phase 5 – Erste Abschaltungen, Rolle rückwärts, Fukushima-Wende (2003–2011)

| Jahr       | Ereignis                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------ |
| 2003       | Abschaltung **Stade** – erstes KKW nach dem Konsens vom Netz                                                       |
| 2005       | Abschaltung **Obrigheim**                                                                                          |
| Okt. 2010  | **Laufzeitverlängerung** durch Schwarz-Gelb (Merkel/Westerwelle) – im Schnitt rund 12 Jahre längere Restlaufzeiten |
| 11.03.2011 | **Reaktorkatastrophe von Fukushima** (Japan)                                                                       |
| 14.03.2011 | **Atom-Moratorium**: sofortige vorübergehende Abschaltung der acht ältesten Reaktoren                              |
| 30.06.2011 | Bundestag beschließt mit breiter Mehrheit den **endgültigen Atomausstieg bis Ende 2022** (13. Atomgesetz-Novelle)  |

## Phase 6 – Der schrittweise Ausstieg (2011–2022)

| Datum      | Ereignis                                                                              |
| ---------- | ------------------------------------------------------------------------------------- |
| 2015       | Abschaltung **Grafenrheinfeld**                                                       |
| 2017       | Abschaltung **Gundremmingen B**                                                       |
| 2019       | Abschaltung **Philippsburg 2**                                                        |
| 2020       | **Gorleben** scheidet im Standortauswahlverfahren als mögliches Endlager aus          |
| 31.12.2021 | Abschaltung **Brokdorf, Grohnde, Gundremmingen C**                                    |
| Feb. 2022  | Russischer Angriff auf die Ukraine – Energiekrise stellt Ausstiegstermin infrage      |
| Okt. 2022  | Kanzler Scholz ordnet **Streckbetrieb** der drei letzten Meiler bis 15. April 2023 an |

## Phase 7 – Endgültiger Ausstieg und Nachspiel (2023–2026)

| Datum      | Ereignis                                                                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 15.04.2023 | **Endgültige Abschaltung** der letzten drei Kernkraftwerke – Emsland, Isar 2, Neckarwestheim 2                                                 |
| 2024       | Wiederkehrende Debatten über eine Neubewertung; laut Umfragen befürwortet eine knappe Mehrheit den Wiedereinstieg                              |
| Juni 2025  | Bundeskanzler Friedrich Merz bezeichnet den Kernkraftausstieg als „strategischen Fehler" – hält eine Rückkehr aber für faktisch kaum umsetzbar |
| Okt. 2025  | Sprengung der Kühltürme des stillgelegten Kraftwerks Gundremmingen – symbolisches Ende einer Ära                                               |
| März 2026  | EU-Kommissionspräsidentin von der Leyen kündigt beim Kernenergiegipfel in Paris eine „Renaissance der Kernenergie" an                          |
| April 2026 | Unionsfraktionschef Jens Spahn fordert Debatte über Wiedereinstieg; Studien beziffern Reaktivierung auf rund 9–10 Mrd. Euro                    |
